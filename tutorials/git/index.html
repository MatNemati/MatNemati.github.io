Git

دستورات و مفاهیم پایه، برای مرور سریع

Source Control / Version Control

سیستمی برای ثبت، مدیریت و پیگیری تغییرات فایل‌ها در طول زمان که امکان مشاهده تاریخچه، مقایسه نسخه‌ها، بازگشت به نسخه‌های قبلی و همکاری چند نفر روی یک پروژه را فراهم می‌کند. هدف اصلی آن جلوگیری از گم‌شدن یا خراب‌شدن تغییرات و مشخص بودن اینکه چه چیزی، چه زمانی و توسط چه کسی تغییر کرده است.

Diff

ابزاری برای مقایسه دو فایل و نمایش تفاوت‌های آن‌هاست؛ مشخص می‌کند چه خطوطی در فایل اول و دوم اضافه، حذف یا تغییر کرده‌اند. در خروجی Unified Diff، علامت - نشان‌دهنده حذف و + نشان‌دهنده اضافه‌شدن است.

diff A B diff -y A B # Side-by-side comparison diff -u A B # Unified Diff format

KDiff3 / Meld

ابزارهای گرافیکی برای مقایسه و ادغام فایل‌ها؛ KDiff3 برای Linux و Meld برای macOS قابل استفاده است.

Patch / Patching

Patch فایلی است که تفاوت بین دو نسخه را ذخیره می‌کند و می‌توان از آن برای اعمال تغییرات روی فایل اولیه استفاده کرد. Patching فرایند اعمال این تغییرات روی فایل هدف برای تبدیل آن به نسخه جدیدتر است.

diff -u A B > patch.diff patch A < patch.diff

Creating a Patch

با استفاده از diff و عملگر >، خروجی تفاوت دو فایل در یک فایل جدید ذخیره می‌شود. این فایل همان Patch است و تغییرات لازم برای تبدیل فایل A به B را در خود دارد.

diff -u A B > patch.diff

Applying a Patch

با دستور patch و عملگر <، Patch روی فایل اولیه اعمال می‌شود. در نتیجه فایل A تغییر می‌کند و به محتوای نسخه B می‌رسد.

patch A < patch.diff
